## Bug

agent 走 `open-tag attachment upload` 上传的一切附件都是强制下载卡，无法内联预览。
根因：CLI 构造 `new Blob([bytes])` 不带 `{ type }`，undici 一律发
`application/octet-stream`；服务端照存，serve 时落 Tier 3 强制下载。
人类网页上传不受影响（浏览器自动带正确 MIME）。

## 修复（两层）

1. **CLI** `src/cli/mime.ts`（新）：扩展名→MIME 表（png/jpg/gif/webp/pdf/md/html/txt/mp4…），
   `mimeFor()` 大小写不敏感、只认末段扩展；未知扩展 fail-closed octet-stream。
   `src/cli/index.ts` 上传处 `Blob { type: mimeFor(file) }`。
2. **服务端兜底** `src/server/attachments.ts` `sniffMimeType()`：声明为 octet-stream 的
   上传按魔数嗅探——PNG/JPEG/GIF/PDF 四种（全部已在 serve 白名单 SAFE_INLINE_TYPES 内，
   嗅错最坏显示坏图、绝不引入可执行类型）。只在 `application/octet-stream` 时替换，
   **绝不覆盖客户端显式声明**。parseUpload 用 Transform 流式 peek 首块，不整文件缓冲。
   兜住旧版 CLI 与其它第三方客户端。
